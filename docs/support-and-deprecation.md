# Support and deprecation

The dev reference app is supported by the Simply360 platform team at
`developers@simply360.app`. Security reports use private GitHub Security
Advisories.

For a functional report, include the repository SHA, deployed SHA, environment,
public installation and operation Simply IDs, UTC timestamp, request/event
identifier, and redacted error code. Do not include credentials, signed URLs,
file bodies, or customer data.

Breaking manifest, Blueprint, OAuth, webhook, file API, Google API, or state
changes require a new immutable app version, upgrade notes, unchanged-scope or
re-consent classification, migration/rollback steps, and lifecycle tests.
Dev versions may be retired only after installations are suspended or
upgraded and cleanup evidence is recorded.

This proof has no production SLA. Production support terms, notice periods,
stable package publication, and marketplace retirement policy remain part of
the separately approved GA plan.
